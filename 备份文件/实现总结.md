## 技术实现亮点

### 1. 场景生成
```python
# AR(1)模型 + 负相关性
generation → spot_price (correlation = -0.6)
```

### 2. 场景树构建
```python
# K-means聚类，基于周平均价格
features = weekly_avg_spot_price
clusters = KMeans(n_clusters=branching_factor)
```

### 3. 优化模型
```python
# 线性规划
max Σ P_s * r_{s,t}
s.t. 能源平衡、风险约束、非预见性
```

### 4. 风险管理
```python
# 三层风险约束
- 周度CVaR ≥ 500 kR$
- 月度CVaR ≥ 3000 kR$
- 回撤 ≤ 300 kR$
```

## 注意事项

### 1. 计算资源
- 完整案例需要5-10分钟
- 建议先运行简化示例
- 可通过减少场景数加速

### 2. 求解器
- 默认使用CBC求解器（免费）
- 可选用商业求解器（Gurobi, CPLEX）提升性能
- 大规模问题建议使用SDDP

### 3. 参数调整
- 风险约束不宜过严（可能无解）
- 场景数影响计算时间和精度
- 分支因子影响树的复杂度
