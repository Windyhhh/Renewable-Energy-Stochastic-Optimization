# 快速开始指南

## 🚀 5分钟快速上手

### 第一步：检查Python环境

打开命令提示符（Windows）或终端（Mac/Linux），输入：

```bash
python --version
```

如果显示 `Python 3.7` 或更高版本，说明Python已安装。

**如果未安装Python**，请访问 https://www.python.org/downloads/ 下载安装。

---

### 第二步：安装依赖包

**Windows用户（推荐）**：
1. 双击运行 `install_dependencies.bat`
2. 等待安装完成

**所有用户（命令行）**：
```bash
pip install -r requirements.txt
```

---

### 第三步：验证安装

```bash
python test_installation.py
```

如果看到 `✓ 所有测试通过！`，说明安装成功。

---

### 第四步：运行第一个示例

**Windows用户（推荐）**：
1. 双击运行 `run_simple_example.bat`
2. 等待1-2分钟

**所有用户（命令行）**：
```bash
python examples/simple_example.py
```

---

## 📊 理解结果

### 关键指标

1. **期望利润**: 所有场景的平均利润
2. **风险管理成本**: 风险中性利润 - 风险规避利润
3. **风险管理成本比例**: 通常在5-15%之间

### 结果解读

- **风险中性策略**: 追求最大利润，不考虑风险
- **风险规避策略**: 在满足风险约束下最大化利润
- **差异**: 反映了风险管理的代价

## 🔧 自定义参数

### 修改场景数量

编辑 `examples/simple_example.py`：

```python
num_scenarios = 50  # 改为50个场景（更快）
```

### 修改风险约束

```python
risk_constraints = RiskConstraints(
    alpha=0.95,              # 提高置信水平
    weekly_cvar_min=400.0,   # 调整周度CVaR
    monthly_cvar_min=2000.0, # 调整月度CVaR
    max_drawdown=250.0       # 调整最大回撤
)
```

### 修改发电参数

```python
avg_generation = 80.0  # 改为80 MWh/h
avg_spot_price = 200.0 # 改为200 R$/MWh
```

## ❓ 常见问题

### Q1: 提示"python不是内部或外部命令"

**解决**: 
1. 确认Python已安装
2. 将Python添加到系统PATH
3. 重启命令提示符

### Q2: 安装依赖时出错

**解决**:
```bash
# 升级pip
python -m pip install --upgrade pip

# 使用国内镜像
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### Q3: 求解时间太长

**解决**:
- 减少场景数（如从2000减到500）
- 减少阶段数（如从4减到3）
- 先运行简化示例

### Q4: 模型无可行解

**解决**:
- 放松风险约束（降低CVaR阈值）
- 检查参数设置是否合理
- 查看错误信息
