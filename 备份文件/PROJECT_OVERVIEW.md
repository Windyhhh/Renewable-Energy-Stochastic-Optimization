# 项目概览

## 项目背景

本项目实现了期刊论文中提出的**可再生能源交易多阶段随机优化模型**。该模型旨在帮助可再生能源发电企业（如风电场）在不确定性环境下制定最优的远期合约交易策略。

### 核心问题

**问题**: 可再生能源发电企业如何在以下不确定性条件下最大化利润？
- 发电量不确定（受天气影响）
- 现货价格波动
- 远期合约价格变化

**解决方案**: 多阶段随机优化模型
- 同时考虑短期（运营）和长期（战略）不确定性
- 通过场景树建模未来不确定性
- 使用风险约束确保策略稳健性

## 模型特点

### 1. 双尺度决策树
- **战略层**: 周度远期合约决策
- **运营层**: 小时级现货市场交易

### 2. 时间一致性风险管理
- **周度CVaR约束**: 每周最坏情况利润下限
- **月度CVaR约束**: 整月最坏情况利润下限
- **回撤约束**: 限制连续周之间的利润下降

### 3. 相关性建模
- 发电量与现货价格负相关（"鸭形曲线"效应）
- 时间序列相关性（AR模型）

## 数学模型

### 目标函数
```
max Σ_t Σ_s P_s * r_{s,t}
```
最大化所有场景的期望利润

### 主要约束

1. **利润计算**
```
r_{s,t} = 现货收入 + 合约收入 - 发电成本
```

2. **能源平衡**
```
发电 + 合约买入 + 现货买入 = 合约卖出 + 现货卖出
```

3. **非预见性**
- 同一节点的所有场景使用相同决策

4. **风险约束**
- CVaR_{周} >= R_min^w
- CVaR_{月} >= R_min^l
- 回撤 <= θ

## 实现架构

### 模块划分

```
数据生成 → 场景树构建 → 远期定价 → 优化求解 → 结果分析
```

### 核心类

1. **ScenarioGenerator**: 生成相关的发电量和价格场景
2. **ScenarioTree**: 构建多阶段决策树
3. **ForwardPricer**: 计算远期合约价格
4. **TradingOptimizationModel**: 求解优化问题
5. **RiskConstraints**: 管理风险约束

## 案例研究

### 基准案例（复现论文）

**参数设置**:
- 发电机: 160MW风电场，平均100 MWh/h
- 时间范围: 4周（1个月）
- 场景数: 2000个
- 场景树: 每阶段2个分支，共23个节点

**风险约束**:
- α = 90%
- 周度CVaR ≥ 500 kR$
- 月度CVaR ≥ 3000 kR$
- 最大回撤 ≤ 300 kR$

### 预期结果

1. **风险中性策略**
   - 期望利润: ~6.6 MR$
   - 合约量: 接近100%（最大化合约收入）

2. **风险规避策略**
   - 期望利润: ~6.2 MR$（略低）
   - 合约量: 更保守，满足风险约束
   - 风险管理成本: ~400 kR$

## 关键发现

### 1. 动态策略 vs 静态策略

**动态策略优势**:
- 可以根据市场演变调整决策
- 更好的风险管理
- 价值提升约13%

### 2. 风险约束的影响

**回撤约束**:
- 对策略影响最大
- 防止连续亏损

**CVaR约束**:
- 确保最坏情况下的利润下限
- 提供稳定的现金流

### 3. 发电量-价格负相关

**影响**:
- 增加价格-数量风险
- 需要更谨慎的合约策略
- 风险管理更加重要

## 性能指标

### 计算复杂度
- 变量数: O(B^T × C + S × T)
- 约束数: O(B^T × C + S × T)
- 求解时间: 5-10分钟（2000场景，4阶段）

其中:
- B: 分支因子
- T: 阶段数
- C: 合约数
- S: 场景数
