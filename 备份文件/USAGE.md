# 使用指南

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 运行简化示例

```bash
python examples/simple_example.py
```

这个示例使用较少的场景（100个）和阶段（3周），可以快速运行并理解模型的基本功能。

### 3. 运行完整案例研究

```bash
python examples/case_study.py
```

这个案例复现了期刊论文中的研究，使用2000个场景和4个阶段，计算时间较长（约5-10分钟）。

## 模型说明

### 核心组件

1. **场景生成** (`src/data_generation.py`)
   - 生成相关的可再生能源发电量和现货价格场景
   - 使用AR(1)模型模拟时间相关性
   - 模拟发电量与价格的负相关性（"鸭形曲线"效应）

2. **场景树构建** (`src/scenario_tree.py`)
   - 使用K-means聚类算法构建多阶段决策树
   - 基于周平均现货价格进行聚类
   - 支持灵活的分支因子配置

3. **远期定价** (`src/forward_pricing.py`)
   - 基于条件期望现货价格计算远期价格
   - 添加风险溢价
   - 支持不同交割期的合约

4. **优化模型** (`src/optimization.py`)
   - 多阶段随机线性规划模型
   - 目标：最大化期望利润
   - 约束：能源平衡、非预见性、风险约束

5. **风险管理** (`src/risk_measures.py`)
   - 周度CVaR约束
   - 月度CVaR约束
   - 单期最大回撤约束

### 决策变量

- `x_{c,n}`: 合约c在节点n的签约比例 [0, 1]
- `r_{s,t}`: 场景s在阶段t的净收入
- `e_{s,t}^{lg}`: 现货市场卖出量（多头）
- `e_{s,t}^{sh}`: 现货市场买入量（空头）

### 风险约束

1. **周度CVaR**: 每周最坏情况下的平均利润不低于设定阈值
2. **月度CVaR**: 整月最坏情况下的平均利润不低于设定阈值
3. **最大回撤**: 连续两周之间的利润下降不超过设定阈值

## 参数调整

在 `examples/case_study.py` 中修改：

```python
num_scenarios = 1000  # 减少场景数以加快计算
```

### 修改风险约束

```python
risk_constraints = RiskConstraints(
    alpha=0.95,  # 提高置信水平到95%
    weekly_cvar_min=600.0,  # 提高周度CVaR阈值

```

```python
branching_factors = [3, 3, 2, 2]  # 前两阶段3个分支，后两阶段2个分支
```

## 结果解读

2. **合约策略**: 每个节点的最优合约签约比例
3. **现货头寸**: 每个场景在现货市场的买卖量

## 常见问题

### Q1: 求解时间过长怎么办？

A: 可以采取以下措施：
- 减少场景数（如从2000减到500）
- 减少阶段数（如从4周减到3周）
- 简化场景树（减少分支因子）
- 增加求解时间限制

### Q2: 模型无可行解怎么办？

A: 可能的原因：
- 风险约束过于严格，尝试放松约束
- 数据生成参数不合理，检查发电量和价格设置
- 合约定价问题，检查远期价格计算

### Q3: 如何比较不同策略？

A: 运行多次优化，每次使用不同的风险约束参数，然后比较：
- 期望利润
- CVaR值
- 最大回撤
- 合约签约量

## 扩展方向

1. **添加更多合约类型**: 买入合约、期权等
2. **多个发电机组**: 组合优化
3. **更复杂的风险度量**: 下行风险、尾部风险等
4. **样本外验证**: 使用独立场景集验证策略
5. **动态规划求解**: 使用SDDP算法处理更大规模问题
